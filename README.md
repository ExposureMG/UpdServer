# UpdServer by [c0z]

README by Exposure

Xbox 360 XEX that bridges NAND and Storage operations over a local tcp server, allowing for wireless flashing.

Not very commonly used but a client is built directly into xeBuild and J-Runner wraps these in GUI.

Allows for features like flashing an image, wiping a partition, and pushing files / updates over tcp.


## Clients

- xeBuild by [c0z]

- J-Runner with Extras by many people

- UpdClient by ExposureMG
